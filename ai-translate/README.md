# 🌐 AI 翻译工具

我的**第二个 AI 工具** —— 调用 DeepSeek 大模型做中英翻译。

## 功能

粘贴文字 → 选「方向 / 风格 / 附加」→ 一键翻译。

## 比总结工具多练的两个提示词本领

1. **角色设定**：让 AI「扮演一名专业翻译」（而不只是"你是个助手"）。
2. **输出格式控制**：让 AI 不只给译文，还能「附上重点词汇解释」——按你规定的格式交作业。

## 技术栈

| 技术 | 作用 |
|------|------|
| Flask | 网页后端 |
| requests | 调用 DeepSeek API |
| DeepSeek | 大模型（deepseek-chat） |

## 怎么运行

```bash
pip install flask requests
python app.py
# 浏览器打开 http://127.0.0.1:5002
```

## 我学到的新东西

1. **角色设定**：`'你是一名专业翻译，精通中英文'` 比 `'你是个助手'` 更能让结果专业。
2. **输出格式**：在提示词里写明「先输出译文，再用小标题列重点词汇」，AI 就会照做。
3. **temperature 越低越稳定**：翻译用 `0.3`（总结用 `0.7`），因为翻译要准确、不能"跑偏"。
