# ✨ AI 总结提炼工具

我的第一个真正的 **AI 工具** —— 调用 DeepSeek 大模型，把长文章一键总结成要点。

## 它和之前工具最大的区别

| | 之前的工具 | 这个 AI 工具 |
|---|---|---|
| 思路 | 自己写规则（正则判断、统计字数……） | 把活交给大模型 |
| 举例 | "判断这是不是手机号" | "帮我把这段总结成 3 点" |
| 谁在干活 | 我写的代码 | DeepSeek 大模型 |

## 功能

粘贴一篇长文章 → 点「✨ 开始总结」→ DeepSeek 提炼出清晰的要点。

## 技术栈

| 技术 | 作用 |
|------|------|
| Flask | 网页后端框架 |
| requests | 让 Python 去"打电话"给大模型 |
| DeepSeek | 大模型（deepseek-chat） |

## 怎么运行

```bash
pip install flask requests
python app.py
# 浏览器打开 http://127.0.0.1:5001
```

## 一次 API 调用发生了什么

```
网页粘贴文章 → 点「总结」
    ↓ fetch 把文章发给后端
后端 app.py 拿到文章
    ↓ requests 带着 API key 调用 DeepSeek
DeepSeek 验证 key → 用大模型总结 → 返回结果
    ↓
后端把结果发回前端 → 网页显示出来
```

## 关键概念（求职面试常问）

- **API**：别人提供的"接口"，你按规定格式发请求，它就返回结果。
- **API key**：调用接口的"门禁卡"，证明你有资格 + 用于计费。
- **messages 格式**：发给大模型的消息是一个列表，通常包含 `system`（告诉它角色）和 `user`（你的问题）。

## 我学到了什么

1. 什么是 API、怎么调 API（requests 库）
2. 大模型的消息格式（messages / system / user）
3. 前端用 fetch 调后端接口，前后端怎么配合
4. key 要保密
